# Guides for club admins

Step by step, for the people running a club in the admin portal. What each
feature does is in [FEATURES](../FEATURES.md).

| Guide                                                       | For                                                                        |
| ----------------------------------------------------------- | -------------------------------------------------------------------------- |
| [Connect a scoreboard to a sheet](connect-a-scoreboard.md)  | A new scoreboard, a replaced one, or one that says scores are not syncing  |
| [Set up a screen or stream](set-up-a-display.md)            | A warm room TV, a score bug in OBS, or a bonspiel screen                   |
| [Set up leagues](set-up-leagues.md)                         | Adding leagues and their teams, by hand or from a spreadsheet              |
| [Run a bonspiel](run-a-bonspiel.md)                         | Planning one, starting its games on the scoreboards, and its results       |
| [Post results to Slack or Discord](post-results-to-chat.md) | Each finished game in a channel                                            |
| [Share scores with members](share-scores-with-members.md)   | The public scores page for members' phones                                 |

The admin portal's club page has five tabs: **Sheets & Games**, **Leagues**,
**Bonspiels**, **Displays** and **Settings**. Settings has three groups:
**Scoreboards**, **Integrations** and, for super admins, **Users**. A
bonspiel admin sees only Sheets & Games and Bonspiels.
